## What is SkyBubble?

SkyBubble adds floating chat bubbles above player heads in Minecraft, so you can instantly see who is talking without digging through the chat log in the corner of your screen.
Instead of relying on Minecraft's blocky bitmap font, SkyBubble renders text using a MSDF (multi-channel signed distance field) font renderer. This means your chat bubbles stay crisp and readable at any distance or zoom level, instead of looking pixelated or blurry like vanilla text does when scaled in 3D space.

## How it works

SkyBubble is entirely client-side. There is no server-side installation required. You don't need to install anything on the server, and server owners don't need to add this mod for it to work.

Only the viewer needs SkyBubble installed to see bubbles. If you have the mod, you'll see a chat bubble above any player who talks, whether or not they have SkyBubble themselves. If you don't have the mod installed, you won't see bubbles above anyone, even players who do have it. Chat itself still works completely normally either way.

## Current Features

* Floating chat bubbles rendered directly above players in the world
* Fully client-side, no server-side installation needed
* Works for any player talking, even if they don't have the mod installed themselves
* Clean, smooth vector-based font rendering instead of Minecraft's default blocky font
* Bubbles automatically position themselves above the player's nametag
* Multiple messages stack cleanly instead of overlapping

## Planned Features

* Settings UI to let you load and use your own custom fonts
* Adjustable bubble display timer to control how long a bubble stays visible
* Arabic and Chinese text shaping support for proper rendering of those scripts
* Emoji support, including standard Unicode emoji and custom emoji using images or GIFs
* Extend platform support to NeoForge

## Incompatible Mods

* **No Chat Reports Mod**: Currently incompatible due to both mods injecting overlapping chat-related code. Compatibility is planned for a future SkyBubble update.

---

## Why SkyBubble?

Chat in Minecraft can be hard to follow on busy servers, especially with a lot of players talking at once. SkyBubble makes conversations easier to follow by showing who said what, right where you're already looking, in text that's actually pleasant to read.
